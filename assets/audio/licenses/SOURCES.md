# Short-video starter pack sources

The installer verifies every downloaded source and selected file against the
byte size and SHA-256 stored in `catalog.json`. The installed `manifest.json`
retains the creator, source page, license URL, hashes, and modification state.

## Sound effects

- Kenney, Interface Sounds: https://kenney.nl/assets/interface-sounds
- Kenney, Impact Sounds: https://kenney.nl/assets/impact-sounds
- Kenney license information: https://kenney.nl/support

Selected OGG files are extracted byte-for-byte from the two published ZIP
archives. No audio modification is performed during installation.

## Background music

- hernandack, Short Loops Background Music Pack:
  https://opengameart.org/content/short-loops-background-music-pack

The four selected OGG files are downloaded byte-for-byte from the files linked
on that source page. No audio modification is performed during installation.
