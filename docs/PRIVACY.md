# プライバシーとデータの取り扱い

- 対象ソフトウェア: Clip Extractor
- 最終更新: 2026-09-07
- 適用バージョン: 本ドキュメントを含むリポジトリのリビジョン

> **注意（法務レビュー未了）**: 本文書は実装内容に基づき配布者（machaniconico、個人）が作成したもので、法律専門家によるレビューをまだ受けていません。残る未解決事項は [`docs/compliance/`](compliance/) の各記録を参照してください。

---

## 1. 要点

- **本ソフトはあなたのPC上で動作します。** 配布者はテレメトリ・使用状況・動画・文字起こし・認証情報のいずれも受け取りません。配布者が運用するサーバーはありません。
- **外部へデータが出るのは、あなたが有効にした連携機能の分だけです。** 送信先はあなた自身が契約した各APIサービス（Google / OpenAI / X / YouTube など）であり、そこでの取り扱いは各社のポリシーに従います。
- **認証情報はあなたのPCにのみ保存されます。** Windows では OS の DPAPI で暗号化します。**Windows 以外（WSL / Linux / macOS）は平文で保存されます。**

Web UI は `127.0.0.1:7860`（ループバック）にのみバインドされ、同一LAN上の他端末からは接続できません。

## 2. 外部へ送信されるデータ

| 送信先 | 送信されるもの | 発生条件 | 既定 |
|---|---|---|---|
| Google Gemini API | 文字起こしテキスト＋プロンプト（**動画・音声そのものは送信しません**） | ハイライト検出をGeminiで実行したとき（1動画につき1リクエスト、リトライなし） | Web UI では**ON**（既定プロバイダ） |
| OpenAI API | 文字起こしテキスト＋プロンプト | AIプロバイダに OpenAI を選んだとき | OFF |
| Anthropic（`claude` CLI 経由） | 文字起こしテキスト＋プロンプト。送信は同梱でない外部CLIが行います | AIプロバイダに Claude を選んだとき（CLI導入時） | Web UI では OFF |
| ローカルLLM（OpenAI互換サーバー） | 文字起こしテキスト＋スキーマ。**接続先はループバック（127.0.0.1 / localhost / ::1）の `/v1` に限定** | 環境変数 `CLIP_EXTRACTOR_ENABLE_LOCAL_LLM=1` を設定したとき | OFF（実験機能） |
| X API v2 (`POST https://api.x.com/2/tweets`) | 作成された告知本文（配信URLを含む）と OAuth 1.0a 署名 | 「配信開始時にXへ告知する」と「X APIで完全自動投稿する」の**両方をONにし、認証情報4項目を保存したとき** | OFF（二重オプトイン） |
| X（ブラウザの投稿画面 `x.com/intent/post`） | 告知本文（URLクエリとして既定ブラウザへ渡します。APIには送りません） | 自動投稿が無効、または API 投稿に失敗したとき | 上記に準ずる |
| YouTube Data API v3 | 動画メタデータ（タイトル・説明文・配信ID）と OAuth トークン | ライブ配信URLの取得、概要欄タイムスタンプの自動追記を使うとき | OFF（`credentials.json` 未設定ならスキップ） |
| Google Drive API v3 | **出力ディレクトリ配下の全ファイル**（動画・SRT・XML・サムネ等） | Driveアップロードを実行したとき | OFF |
| YouTube / Twitch（yt-dlp） | 取得対象のURLへの通常のダウンロードアクセス | URLを入力して動画を取得するとき | 入力方式による |
| OBS WebSocket | 接続パスワード、シーン制御コマンド | OBS連携を開始したとき。既定の接続先は `localhost` | OFF（既定ホストはローカル） |
| Premiere Pro 連携ブリッジ | ローカル `127.0.0.1` のみ。外部送信なし | Premiere連携を使うとき | — |

**無料枠での注意（Gemini）**: Google は無料枠での送信内容と生成結果を製品改善に利用し、人が内容を確認する場合があります。個人情報・機密情報を無料枠へ送信しないでください。有効な課金アカウントに紐づく有料利用ではこの利用はされないとされています。詳細は [Gemini API 追加規約](https://ai.google.dev/gemini-api/terms) を確認してください。

## 3. PC上に保存されるもの

| 保存物 | 場所 | 内容 | 削除方法 |
|---|---|---|---|
| `.gemini_key` | インストールディレクトリ直下 | Gemini APIキー | UIで空欄にして保存、またはファイルを削除 |
| `.obs_password` | 同上 | OBS WebSocket パスワード | 同上 |
| `.x_credentials.json` | 同上 | X の API Key / API Key Secret / Access Token / Access Token Secret | 同上 |
| `default_settings.json` | 同上 | UI設定（**認証情報は保存対象から除外されます**） | ファイルを削除すると初期設定に戻ります |
| `credentials.json` / `token.json` / `youtube_token.json` | Windows: `%APPDATA%\clip-extractor`、macOS: `~/Library/Application Support/clip-extractor`、Linux: `$XDG_CONFIG_HOME` または `~/.config/clip-extractor` | Google OAuth クライアント情報とアクセストークン | 当該ファイルを削除し、Googleアカウント側でもアクセスを取り消してください |
| アプリログ | `%TEMP%\clip-extractor-logs\app_YYYYMMDD_HHMMSS.log` | 動作ログ。**自動削除されません** | フォルダごと削除 |
| フォントキャッシュ | `%TEMP%\clip-extractor-logs\font_cache.json` | 検出したフォント一覧 | 同上 |
| 出力ファイル | 既定 `./output`（実行ごとに `output_YYYYMMDD_...` を作成） | 切り抜き動画・ショート・字幕・サムネ・XML | フォルダごと削除 |

文字起こしの結果をディスクに保存する常設キャッシュはありません（同一プロセス内のモデル再利用のみで、終了時に破棄されます）。

### 認証情報の保護レベル

- **Windows**: 3つのサイドカー（`.gemini_key` / `.obs_password` / `.x_credentials.json`）は、ユーザースコープの Windows DPAPI で暗号化して保存されます。旧バージョンが作った平文ファイルは、初回読み込み時に自動で暗号化形式へ移行します。DPAPI は「同じWindowsユーザー・同じPC」に復号を紐づけますが、**そのユーザー権限で動作するマルウェアからは保護しません**。
- **Windows 以外（WSL / Linux / macOS）**: 現状は**平文のまま保存されます**（開発互換のためのフォールバック）。機密性が必要な環境では、これらのプラットフォームで認証情報を保存しないでください。

## 4. ログに含まれ得るもの

- X 投稿の失敗については、HTTPレスポンス本文と下位ライブラリの例外文字列を**記録も表示もしません**。表示されるのは固定のカテゴリ名とHTTPステータスのみです。認証情報の読み書き失敗も、例外の種類名だけを記録します。この不変条件は自動テスト（`tests/test_error_hygiene.py`）で継続的に検証しています。
- 一方で、**パイプライン全体の処理エラーやOBS関連の一部エラーでは、ライブラリが投げた例外文字列やトレースバックが処理ログ欄とログファイルに出力されます。** ファイルパスや外部サービスのエラーメッセージが含まれる可能性があります。**ログを第三者へ共有する前に内容を確認してください。**

## 5. 停止・失効の手順

- **X への自動投稿を止める**: 「X APIで完全自動投稿する」をOFFにします。以後 API へのリクエストは発生しません。
- **X のアクセスを完全に失効させる**: X Developer Console でトークンを失効／再生成し、インストールディレクトリの `.x_credentials.json` を削除します。
- **Gemini / OpenAI**: UIでキーを空欄にして保存（ファイルが削除されます）。必要に応じて各コンソールでキー自体を失効させてください。
- **Google（YouTube / Drive）**: 保存先ディレクトリの `token.json` / `youtube_token.json` を削除し、Google アカウントの「サードパーティのアクセス」から本アプリの権限を取り消してください。
- **全データの削除**: 上表のファイルとログフォルダ、出力フォルダを削除すれば、本ソフトが作成したデータは残りません。

## 6. 対象利用者

本ソフトは日本国内に居住する18歳以上の方を対象に配布します。日本国外の方（EEA・スイス・英国を含む）および18歳未満の方は対象外です。Gemini API は業務・専門用途向けで利用者は18歳以上である必要があり、EEA・スイス・英国では有料サービスのみ利用できるため、対象地域をこのように限定しています。各外部APIの年齢・地域要件は、あなたが契約する各サービスの規約に従います。

サポート対象OSは Windows 10 / 11 のみです。認証情報の暗号化保存（DPAPI）は Windows でのみ機能し、その他のOSではサポート対象外のため、その環境での保存形態について配布者は保証しません。
